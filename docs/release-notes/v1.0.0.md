First release. psafe3 Opener opens Password Safe V3 (`.psafe3`) files offline and lets you add, edit and delete entries, save with rotating backups (`.bak`, `.bak2`, `.bak3`), restore from a backup, and export to Password Safe XML for other password managers. Windows opens files read-only in this version.

Always keep a copy of your database before trying a new app with it.

### Checks not yet run for this release

The automated suite passes on macOS, Windows and Linux, and the app was tested by hand on an Apple Silicon Mac with a real file. These manual items from `docs/release-checklist.md` have not been run yet:

- Clean install on an Intel Mac
- Force-quitting the app during a save
- Lock-file behaviour while Password Safe 1.25.0 has the same file open
- Importing the XML export into KeePass 2.x and Bitwarden
- A VoiceOver pass
